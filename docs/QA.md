# 3D 版验证记录

验证日期：2026-09-27。版本：2.0.0。

## 自动验证

资源引用、JavaScript 语法和构建检查通过。共 18 项测试：

- 8 项谜题规则：完整通关、错误密码、前置条件、物品消耗、分级提示、异常存档恢复、重复操作、通关状态冻结。
- 7 项 3D 导航规则：初始点和调查点合法、大步移动不能穿桌和越墙、碰撞后可沿边滑动、斜向速度一致、镜头相对方向、距离调查、错误人物存档恢复及全部机关可达。
- 3 项发布工具验证：仓库名、已有仓库保护、文件白名单与二进制完整性。

## 桌面实际操作

通过游戏正常按钮和键盘控制人物，完成了从起点到结局的整个流程：

走到挂钟读取校时标签 → 返回书桌输入密码取钥匙 → 走到书柜使用钥匙 → 选择紫外线手电并走到星图显影 → 走到保险柜设置符号取保险丝 → 走到配电箱安装保险丝并送电 → 走到出口输入密码 → 成功逃脱。

同时验证：

- 向书桌连续前进时停在桌前，不能穿透家具。
- 抽屉和出口输入错误密码、电路使用错误组合时，不会推进机关。
- 在书柜取得手电后刷新，人物坐标、道具和 2 / 5 机关进度仍然存在。
- W 短按移动、E 调查、F 手电开关和 J 手记快捷键正常。
- 场景拖动能转向，窗口打开时停止人物移动。
- 恐怖效果开关和画质选择可操作；声音开启与关闭状态正确。
- 重新开始经过确认后回到入口，清空本次谜题进度。
- 无应用自身的未捕获控制台错误。

## 手机尺寸预览

在 390 × 844 的独立页面视口中检查了响应式布局，页面宽度和内容宽度均为 390，无横向溢出。通过正常指针拖动摇杆，将人物从 Z 3.0 移动到 Z 1.8；近处书桌调查按钮变为可用。拖动转向、打开调查窗口和环境音切换正常。

这属于浏览器内的手机尺寸与指针操作验证，不等同于 iOS / Android 真机测试。

## 渲染与验证边界

测试浏览器禁用了 WebGL，因此实际通关和截图在软件 3D 兼容渲染器中完成。兼容模式使用同一份 3D 网格、人物动画、透视相机和碰撞规则，并用深度缓冲处理遮挡；画质和帧率比 GPU 模式低。

Three.js WebGL 2 路径及其动态阴影、光照代码通过构建和语法检查，但当前环境未做真实 GPU 渲染测试。浏览器检测到 WebGL 不可用时会自动进入兼容模式；不能据此宣称所有显卡或手机性能都已验证。

谜题存档保留 v1 格式；3D 坐标与设置分开保存。多个同源标签页仍共享浏览器存档，以最近写入的内容为准。

GitHub Pages 通过工作流重新构建并发布 dist。线上是否完成更新，以本次工作流的成功状态和实际网页返回内容为准。
